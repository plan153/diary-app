# 📓 Diary App

> AI 공감 일기 · 아이콘 영어 일기 · 자동 라이프 아카이브 · 콘텐츠 스튜디오

## Apps
| App | Description |
|-----|-------------|
| 🎙️ ECHO | AI 공감 대화 → 일기 자동 생성 |
| ⚡ DAYLY | 아이콘 클릭 → 영어 일기 |
| 🌐 MEMOIR | 센서 데이터 → LLMWiki 타임라인 |
| 🎬 Content Studio | 일기 → 인스타·틱톡·뉴스레터 자동화 |

## Setup
Requires an [Anthropic API Key](https://console.anthropic.com).

## Tech Stack
- React 18 + Vite 5
- Anthropic Claude API (claude-sonnet-4-20250514)
- localStorage for persistence
